# Лендинг «Каркас74» (каркасные дома, Челябинск)

Одностраничный сайт на базе экспортированного Design Component (`<x-dc>` + `dc-runtime`). Готов к публикации после заполнения настроек и подключений.

## Состав

- `index.html` — страница лендинга (разметка, стили и логика).
- `assets/` — изображения и видео (герой, проекты, кейсы).
- `support.js`, `vendor/react.js`, `vendor/react-dom.js` — рантайм рендера компонента (не редактировать).

## Быстрый запуск локально

Нужна раздача по HTTP (на `file://` скрипты могут блокироваться браузером):

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`.

## Что настроить перед публикацией

Все основные параметры вынесены в объект `site` внизу `index.html` (класс `Component`, блок `// Настройки сайта`):

- **Контакты и реквизиты:** `company`, `inn`, `ogrn`, `legal`, `phone`, `phoneHref`, `address`, `hours`.
- **Ссылки:** `maxUrl`, `vkUrl`, `tgUrl`.
- **Аналитика:** `metrikaId` — номер счётчика Яндекс Метрики (`0` — события не отправляются). Сам скрипт подключения счётчика на страницу нужно добавить отдельно, если используется Метрика.
- **Форма заявок:** `formEndpoint` — URL, на который отправляется POST JSON (`name`, `phone`, `project`, `contact`, `page`). Если пусто, заявка считается принятой локально, а данные выводятся в консоль браузера.
- **Карта:** `mapEmbedUrl` — `src` для iframe виджета карты (например, виджет Яндекс Карт). `mapLink` — ссылка «Открыть на Яндекс Картах». Если `mapEmbedUrl` пуст, показывается заглушка со ссылкой.

Также проверьте и при необходимости замените:
- тексты, цены, сроки и состав проектов/кейсов;
- фотографии этапов в кейсах (сейчас могут использоваться общие изображения из `assets/`);
- текст политики обработки персональных данных в секции `#policy` (шаблон — требуется проверка юристом и актуальные реквизиты оператора).

## Примечания

- В `<head>` добавлены viewport, базовые meta/OG-теги и favicon (data URI).
- Форма выполняет клиентскую валидацию (имя, телефон, согласие) и отправку на `formEndpoint` при наличии.
- Разметка и стили в основном inline (как в экспортном макете); при развитии проекта имеет смысл перенести дизайн в обычную компонентную/сборочную структуру.
